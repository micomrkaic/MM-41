| `today` | `-- date` | today's date as a string d.m.yyyy | `today` |
| `now` | `-- "HH:MM"` | push the current local time as a string, same form as sunrise/sunset | `now` |
| `tz_offset` | `date zone -- hours` | UTC offset in hours of an IANA zone on the given date, DST included | `"1.12.2026" "America/New_York" tz_offset` |
| `ddays` | `d1 d2 -- n` | days from date d1 to date d2 (d2 - d1) | `"1.1.2025" "31.12.2025" ddays` |
| `dateplus` | `date n -- date2` | the date n days later (n may be negative) | `"1.1.2025" 30 dateplus` |
| `dow` | `date -- name` | weekday name of a date | `"1.1.2025" dow` |
| `edmy` | `date -- y m d` | split a date into year, month, day (day on top) | `"1.1.2025" edmy` |
| `num2date` | `d m y -- date` | build a date string from day, month, year | `1 1 2025 num2date` |
| `days2eoy` | `date -- n` | days from the date to the end of its year | `"1.1.2025" days2eoy` |

## Workdays

| Command | Stack | Description | Example |
|---|---|---|---|
| `workdays` | `d1 d2 -- n` | workdays from d1 to d2, both inclusive (Excel NETWORKDAYS): Mondays to Fridays not in the holiday calendar; negative if d2 < d1 | `"1.1.2026" "31.12.2026" workdays` |
| `workdayplus` | `date n -- date2` | the date n workdays after date (n may be negative; the start date is not counted, as Excel WORKDAY) | `"24.12.2026" 10 workdayplus` |
| `isworkday` | `date -- flag` | 1 if the date is a Monday to Friday and not a holiday | `20261126 isworkday` |
| `holidays` | `name -- H` | the holiday calendar as a vector of YYYYMMDD: the file holidays/name.txt in the config directory, or the built-in rules "us" (federal, observed) and "si" (Slovenia) for the years around today | `"us" holidays` |
| `yholidays` | `year name -- H` | the built-in rules for one year | `2027 "si" yholidays` |
| `sethol` | `H --` | install a vector of dates YYYYMMDD as the holiday calendar for this session | `[2 1 $ 20261126 20261225] sethol` |
| `usehol` | `name --` | install the calendar `name` (file or rules) and remember it in config.txt | `"us" usehol` |
| `clrhol` | `--` | remove the holiday calendar (weekends only) and forget it in config.txt | `clrhol` |
| `hol` | `-- H` | the installed holiday calendar as a vector | `hol` |
