A programmable RPN calculator: real, complex and decimal numbers, strings, matrices.

Manual Commands Source

Enter runs the line · ↑ ↓ earlier lines · Tab completes · Ctrl+L clears the screen · drop a file here to give it to the calculator

Try it

Numbers go on the stack; a command takes what it needs from the top and leaves its result there. Click a line to run it.

Files

Files you add are in the calculator's directory: "table.txt" readmat, "prog.rpn" load. Files it writes appear here.
